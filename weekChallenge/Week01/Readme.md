# Week 01 - Sloppy RPG

> KTB 위클리 챌린지 1주차 — CLI 기반 RPG 게임 접속 시스템

---

## 목표

커맨드라인에서 동작하는 RPG 게임 인증 시스템 구현

- 계정 생성 / 로그인 / 계정 삭제
- AES-CBC 암호화를 통한 비밀번호 보안 처리
- JSON 파일 기반 유저 데이터 영속성

---

## 프로젝트 구조

```
Week01/
├── sloppygame.py          # 메인 진입점 (CLI 라우팅)
├── utils/
│   ├── loginUtils.py      # 로그인 인자 파싱 및 검증
│   └── menuUtils.py       # 로그인 후 메인 메뉴 처리
├── user/
│   ├── utils.py           # 유저 CRUD, AES 암호화/복호화
│   └── userLoginData.json # 유저 데이터 저장소
└── requirements.txt
```

---

## 설치 및 실행

**의존성 설치**

```bash
pip install pycryptodome
```

**계정 생성**

```bash
python3 sloppygame.py create --id <아이디> --pwd <비밀번호>
```

**로그인**

```bash
python3 sloppygame.py login --id <아이디> --pwd <비밀번호>
```

## 주요 기능

### 인증 흐름

| 상황 | 결과 |
|---|---|
| ID 없음 | `해당 아이디가 존재하지 않습니다` 출력 |
| ID 있음 + 비밀번호 불일치 | `비밀번호가 옳지 않습니다` 출력 |
| ID 있음 + 비밀번호 일치 | 로그인 성공 → 메인 메뉴 진입 |
| 이미 존재하는 ID로 생성 시도 | `이미 존재하는 ID입니다` 출력 |

### 메인 메뉴 (로그인 후)

```
1. 게임 접속    → 로딩 애니메이션 후 서버 준비 중 안내
2. 계정 삭제    → 확인 후 JSON에서 유저 데이터 제거
3. 게임 종료    → 종료 메시지 출력
```

### 비밀번호 보안

- `pycryptodome`의 AES-CBC 방식으로 암호화
- IV + 암호문을 Base64 인코딩하여 JSON에 저장
- 평문 비밀번호는 어디에도 저장되지 않음

---

## 데이터 형식

`user/userLoginData.json`

```json
{
  "Users": {
    "userId": "<base64(IV)><base64(암호문)>"
  }
}
```
